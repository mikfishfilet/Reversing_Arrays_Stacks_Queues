Array, Stack, and Queue Reversal 

Description 

This Java program asks the user how many integers they want to enter and stores those values in three different collections: an integer array, a stack, and a queue. 

The program displays the original values in each collection, reverses the values, and then displays the reversed results.

Program Requirements 

Prompts the user to enter the number of integers. 

Uses a Scanner to collect user input. 

Stores the integers in an array, a Stack<Integer>, and a Queue<Integer>. 

Displays the original values in all three collections. 

Reverses the array by swapping elements within the original array. 

Reverses the stack using a temporary stack. 

Reverses the queue using a stack. 

Displays the reversed values with clear labels. 

Concepts Used 

Arrays: Store integer values in indexed positions. 

Stacks: Use last-in, first-out (LIFO) behavior. 

Queues: Use first-in, first-out (FIFO) behavior. 

Loops: Collect, display, and reverse values. 

Swapping: Rearranges the elements in the original array. 

Scanner: Reads integer input from the user. 

How to Run 

Open the project in a Java IDE, such as IntelliJ IDEA. 

Make sure the source file is named Main.java. 

Run the Main class. 

Enter the number of integers you want to use. 

Enter each integer when prompted. 

View the original and reversed values for the array, stack, and queue. 

Example Output 

Enter any set amount of integers: 5 
Enter an integer 1: 10 
Enter an integer 2: 20 
Enter an integer 3: 30 
Enter an integer 4: 40 
Enter an integer 5: 50 
 
Original array: 10, 20, 30, 40, 50 
The values in the Stack collection are now: 10 20 30 40 50 
The values in the Queue collection are now: 10 20 30 40 50

The reversed values in the Queue collection are now: 50 40 30 20 10 
 

Purpose 

The purpose of this program is to demonstrate how arrays, stacks, and queues store and organize data, and how different techniques can be used to reverse the order of their elements.
